# LLM Red Teaming Portfolio

Documented practice in LLM red teaming by Rashidah Carr, CISSP. This repo tracks technique study and strategy journals from practice on sanctioned platforms: my thought process, the strategies I tried, and why each one succeeded or failed. It does not publish working breaks.

## Scope and ethics

- All work is performed only on sanctioned platforms or authorized engagements: Gray Swan Arena and Proving Ground, Lakera Gandalf: Agent Breaker, and HackAPrompt.
- No working breaks are published here: no successful prompts, no transcripts, and no harmful model output. Entries describe strategy and reasoning at the technique level.
- Each platform's rules on sharing are followed. Strategy notes for a live challenge stay private until the challenge closes, since a detailed successful strategy can work as a solution.
- Anything that looks like a real-world vulnerability is reported through the vendor's disclosure channel, not posted here.
